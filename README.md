# Warband Together

A co-op campaign mod for Mount & Blade: Warband, built on WSE2. Players share one campaign map with their own persistent characters and fight battles together. The goal is full parity with the native singleplayer campaign.

[![Roadmap status](https://warbandtogether.dev/progress.svg)](https://warbandtogether.dev)

The project is in early alpha. The [roadmap](https://warbandtogether.dev) tracks what works in co-op, feature by feature.

- **Play:** download the [latest release](https://github.com/Night1099/WarbandTogether/releases/latest) and follow the [install guide](docs/INSTALL.md).
- **Build from source:** see the [build guide](docs/BUILD.md).
- **Contribute:** see [CONTRIBUTING.md](CONTRIBUTING.md). Third-party licenses are in [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md).
